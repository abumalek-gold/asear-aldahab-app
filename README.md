# أسعار الذهب (أبو مالك)

تطبيق أندرويد لمتابعة أسعار الذهب في مصر لحظة بلحظة.

## التحميل

حمّل أحدث نسخة من التطبيق من صفحة [الإصدارات](../../releases). دوس على ملف `AbuMalik-Gold.apk` وهيبدأ التحميل مباشرة.

بعد التحميل افتح الملف على موبايلك وثبّته (ممكن يطلب منك السماح بتثبيت تطبيقات من مصادر خارجية مرة واحدة).

## الموقع
